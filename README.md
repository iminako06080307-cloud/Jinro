# 🤖 AI人狼 — AIが役を演じる人狼ゲーム

AIプレイヤー同士が人狼をプレイする様子を観戦するアプリです。
人狼AIは正体を隠して嘘をつき、村人・占い師・ボディーガードのAIは発言の矛盾から推理します。
`index.html` をブラウザで開くだけで動きます。

## 特徴

- **AIが役職を演じる**：各AIは1手ごとに「公開発言(speech)」と「本音(thought)」を返します
- **本音の可視化**：「🔬 AIの本音を表示」をオンにすると、公開発言の裏でAIが何を考えていたか——
  人狼が村人になりすます計画、占い師が結果公開を迷う様子、人狼が仲間を探る疑心暗鬼——を並べて観察できます
- **夜の行動も観戦可能**：襲撃・占い・護衛も本音つきで見られます（本音表示オフの間はネタバレ防止のため伏せられます）

## この村のルール

- **1日目の昼（議論）からスタート**します。初夜はありません
- 🛡️ **ボディーガード**：毎晩、自分以外の一人を護衛します。護衛された人はその夜襲撃されても死にません。
  **自分自身は守れません**
- 🐺 **人狼同士はお互いが誰か分かりません**。発言から仲間を推測するしかなく、
  夜の襲撃で**誤って仲間の人狼を殺してしまう**こともあります
- 昼は全員が議論 → 投票で最多得票者を追放（同数なら追放なし）
- 村人陣営は人狼の全滅で勝利、人狼陣営は村人陣営の数を人狼以下にすれば勝利

## 役職

| 役職 | 陣営 | 能力 |
|------|------|------|
| 👨‍🌾 村人 | 村人 | 能力なし。議論と投票で人狼を探す |
| 🐺 人狼 | 人狼 | 夜に一人を襲撃。仲間の人狼が誰かは分からない |
| 🔮 占い師 | 村人 | 夜に一人を占い、人狼か否かを知る |
| 🛡️ ボディーガード | 村人 | 夜に一人を護衛し襲撃から守る（自分は守れない） |
| 🃏 狂人 | 人狼 | 能力なし。占うと「人狼ではない」。人狼陣営の勝利が目的 |

参加人数は **5〜10人**。人数に応じて上記の役職が自動編成されます（全編成にボディーガード入り）。

## 動作モード

| モード | 説明 |
|--------|------|
| 🎭 デモ（キー不要） | あらかじめ用意した応答でUI・進行を体験できます |
| ✨ 本物のAI | Anthropic APIを使い、実際のAIが推理・欺瞞を行います |

「本物のAI」を使うには [Anthropic Console](https://console.anthropic.com/settings/keys) でAPIキーを取得し、設定画面で入力します。
キーはブラウザの localStorage にのみ保存され、Anthropic以外には送信されません
（`anthropic-dangerous-direct-browser-access` を用いてブラウザから直接APIを呼び出します）。

モデルは Claude Opus 4.8（既定）/ Sonnet 5 / Haiku 4.5 から選べます。

> 💡 「本物のAI」利用時に `file://` で直接開くと環境によってはAPI通信がブロックされることがあります。
> その場合は `python3 -m http.server 8000` などでローカルサーバー経由で開いてください。
> デモモードは `file://` のままで動きます。
