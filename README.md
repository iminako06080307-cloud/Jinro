# 🌙 人狼ゲーム（Werewolf Game）

1台のスマホ／PCを回して遊べる、ゲームマスター補助型の人狼ゲームアプリです。
サーバー不要・オフライン動作。`index.html` を開くだけで遊べます。

## 特徴

- **4〜12人**に対応。人数ごとの推奨編成プリセット付き
- スマホを回して各自こっそり役職を確認する **パス＆リビール方式**
- 夜フェーズ（占い・護衛・霊媒・襲撃）をアプリが順番に案内
- 昼フェーズの **議論タイマー**（2/3/5分）
- 記名式の投票 → 追放 → 勝敗自動判定
- 進行ログと全員の役職を最後に振り返り

## 役職

| 役職 | 陣営 | 能力 |
|------|------|------|
| 👨‍🌾 村人 | 村人 | 能力なし。議論と投票で人狼を探す |
| 🐺 人狼 | 人狼 | 夜に村人を1人襲撃。仲間の人狼が分かる |
| 🔮 占い師 | 村人 | 夜に1人を占い、人狼か否かを知る |
| 📿 霊媒師 | 村人 | 追放者が人狼だったかを知る |
| 🏹 狩人 | 村人 | 夜に1人を護衛し襲撃から守る |
| 🃏 狂人 | 人狼 | 能力なし。占うと「人狼ではない」。人狼陣営の勝利が目的 |
| 🤝 共有者 | 村人 | 共有者同士が味方だと確認し合える |
| 🦊 妖狐 | 第三 | 襲撃では死なないが占いで死ぬ。生き残れば単独勝利 |

## 勝利条件

- **村人陣営**：生存している人狼を全員追放する
- **人狼陣営**：人狼の数が村人陣営の数以上になる
- **妖狐**：ゲーム終了時に生き残っている（単独勝利）

## 遊び方

1. `index.html` をブラウザで開く
2. 参加人数と名前を入力
3. 役職構成を決める（推奨編成ボタンでおまかせも可）
4. スマホを回して各自の役職を確認
5. 画面の案内に従って夜 → 昼 → 投票を繰り返す
6. 勝敗が決まったら全員の役職と進行ログを確認
